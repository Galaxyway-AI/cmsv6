# iCustodian Cross-Site SEO Plan

CMSV6.co.uk should own platform, hosting, solution and support intent. iCustodian.com should own product, category and purchasing intent. Do not duplicate full articles between domains.

## Exact recommended iCustodian changes

1. Create or improve one CMSV6-compatible DVR category/landing page.
   - Suggested title: `CMSV6-Compatible DVRs & Mobile CCTV Systems | iCustodian`
   - Suggested H1: `CMSV6-Compatible DVR and MDVR Systems`
   - Explain that compatibility and available remote functions vary by exact model, firmware, cameras and configuration.
   - Link to `https://cmsv6.co.uk/resources/what-is-cmsv6` with anchor `how CMSV6 remote monitoring works`.
   - Link to `https://cmsv6.co.uk/pricing` with anchor `CMSV6 UK hosting prices`.
   - Link to `https://cmsv6.co.uk/cmsv6-device-compatibility` with anchor `check an existing DVR for CMSV6 compatibility`.

2. Update verified compatible product pages.
   - iC9800MDVR-AI: add `Compatible with CMSV6 live video, GPS and supported AI events when correctly configured.`
   - iC9800MDVR-K: add `Suitable for compatible CMSV6 mobile or fixed-site remote CCTV configurations.`
   - iC-N9DASHCAM: add `Compact four-channel MDVR form with CMSV6 live streaming and supported remote functions.`
   - State the qualifying two-month free-hosting offer with a link to the CMSV6 pricing/terms page.
   - Do not claim every function is included by default.

3. Use reciprocal links selectively.
   - Product pages → relevant CMSV6 solution page, e.g. HGV-capable recorder to `/solutions/lorry-hgv-cctv`.
   - CMSV6 solution pages → the exact relevant product or DVR category with the existing UTM convention.
   - Avoid sitewide keyword-heavy footer links.

4. Improve iCustodian metadata.
   - Homepage should describe vehicle, home and business CCTV products accurately.
   - Product titles should use the verified product name once, followed by the useful type and key capability.
   - Product descriptions must be unique, current and written from actual specifications.
   - Canonicals must point to the single purchasable product URL.

5. Clean template and trust issues.
   - Locate and remove `TEST1`.
   - Remove untranslated, empty or irrelevant template categories.
   - Replace outdated UVMS/CMSV6 references only after checking the actual supported service.
   - Remove empty filters, dummy copy and orphaned category pages.

6. Product structured data.
   - Use Product/Offer only on iCustodian product pages where visible price, currency, stock and seller data are current.
   - Do not copy Product price/availability schema to CMSV6.co.uk when it is not visibly maintained there.
   - Do not add aggregate ratings without genuine eligible reviews.

## Recommended category introduction

> iCustodian supplies compatible DVR and mobile DVR systems for CMSV6 remote CCTV, live video, supported playback and GPS-enabled monitoring. Compatibility and available functions depend on the exact recorder, firmware, cameras, connection and configuration. Qualifying compatible iCustodian DVR purchases include two months of CMSV6 hosting free so customers can configure and test supported remote functions before selecting a paid hosting term.

Implementation requires authorised access to the iCustodian website and product catalogue.
